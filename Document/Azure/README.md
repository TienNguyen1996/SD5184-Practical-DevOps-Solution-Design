# 🚀 GitHub + Azure Pipelines Integration

This folder is used in an automated workflow powered by Azure Pipelines, triggered by changes pushed to GitHub.

## 📘 Setup Instructions

To learn how to connect your GitHub repository to Azure Pipelines and configure YAML-based workflows, refer to the official documentation:

👉 [GitHub integration with Azure Pipelines](https://learn.microsoft.com/en-us/azure/devops/pipelines/repos/github?view=azure-devops&tabs=yaml)

## 📸 Pipeline Result Capture

After each pipeline run, you can view:

- ✅ Build status and logs in Azure DevOps under **Pipelines**
- 📦 Published artifacts (if configured)
- 📊 Deployment history and output (e.g., resource creation, CLI logs)

You may also include screenshots or logs here to document successful runs or errors for team reference.
